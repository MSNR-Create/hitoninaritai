# ゾンビだって暮らしたい！ v1.3 — 描画・通路操作の修正版

スマートフォン向けオフライン対応PWA。GitHub Pagesに静的配置できる構成です。ソースに外部パッケージは不要です。

## 新しい遊び方

- **24×24マップ**：地下は新たな東部・深層区画を開放、地上は6種類の物件（住宅、商店、倉庫、診療所、カフェ、集合住宅）を利用できます。
- **通路**：地下の建設メニューから通路を選び、既存通路の始点をタップ。始点から指またはマウスを動かして、離した位置まで一括施工します。タップ式の始点／終点／再タップ確定も残しています。
- **建物**：最初のタップで配置プレビュー。建設範囲内で再タップすると確定。
- **撤去**：建設メニューの「破壊・撤去」。対象をタップ→同じ対象を再タップで撤去。初期施設・地下出口は保護し、撤去費の返金はありません。
- **建設時カメラ固定**：建設パネルが開いている間はマップ移動・ピンチ拡大・ズームボタンを停止。
- **地上物件**：地上マップの物件をタップすると専用ダイアログ。未契約は「借りる／買う」、所有済みは「貸す／売る」（貸出中は貸出解除）。
- **人間の街**：人間人口、地域信頼、来客数が日次変動。商業売上／維持費／賃料とともに収支に記録。警戒度が高いと人口・来客が減り、経営が不利になります。信頼が高いと警戒度もわずかに改善します。
- **UI**：マップをメニューパネルの裏に埋めないよう、開閉時に視点を再配置します。ページスクロールは原則無効、メニュー内部のみスクロール。

## 実行

```bash
npm start
```

ブラウザで `http://localhost:4173` を開きます。テストは `npm test`。

## セーブ互換性

IndexedDBの旧セーブを読み込めます。新しい区画は旧セーブ読み込み時に補充します。ゲームの地上経営履歴はv1.2から記録します。セーブのJSONバックアップを推奨します。

## 完了していない部分

本版は操作と経済を中心とした開発中ビルドです。スマホ実機でのスワイプ操作は自動検証できていません。人物アニメーションはCanvas描画の試作ドット絵であり、独立したキャラクタースプライトシートや建物種類ごとの全アニメーションは未完成です。人間化後の長期ゲーム進行も未実装です。

## v1.3の修正

- 地面タイルを全描画したあとに建物を奥から手前に描くことで、建物の壁と地面の不自然な重なりを修正。
- 初期の通路データで建物の床下に重なる通路を除去。
- 通路は空き地でドラッグ開始・指を離すだけで施工可能。初めに既存通路に隣接している必要はない。ただし、出口につながっていない施設は停止する。
- 通路の設置費用は新設1マス5G。閉鎖区画・建物上・資金不足の場所には施工できない。
