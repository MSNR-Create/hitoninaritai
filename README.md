# ゾンビだって暮らしたい！ — v1.0.0-rc.1

スマートフォン向けのオフライン対応PWA・リリース候補版。既存Phase 2Eから継続開発したものです。

## 起動

Node.js 18以上を用意して、このフォルダで `npm start`。ブラウザで `http://localhost:4173` を開きます。外部npmパッケージは不要です。HTTPSサーバーに静的配置することもできます。

**スマートフォンで試すとき**：HTTPSでホストしてください。端末からPCのHTTPアドレスにアクセスする方式ではService Workerが動かない場合があります。

## 遊び方

- 地下と地上の16×16マップを切り替える。ドラッグで移動、2本指でズーム、範囲外への移動は制限
- 通路は始点と終点の2タップ。施設はパレットから種類を選び、サイズ付き半透明プレビューを見ながらタップまたはドラッグ終了で設置
- 夜間仕事を割り当てるか、お任せ行動にする。稼ぎ、配給物資を地上で調達する
- 極度の疲労や不足でストライキ、人間からの通報や事件で死亡もあり得る。仲良くなった人間は空き住居があると眷属化
- 研究室を建設し、研究資材を調達し、研究員を配置して衝動抑制を完成。さらに資金500G・研究資材5個で人間化技術を確立し、3つの未来から選べる
- 重要な出来事は、ミニドット絵アニメーション・出来事・原因のイベント小窓で表示。デモ再生ボタンでも確認可能
- セーブは毎朝IndexedDBへ自動保存。手動保存・JSON書き出し・検証付き読み込み・初期化も利用できる。オフライン時は初回オンライン訪問後に静的アセットをキャッシュ

## 自動テスト

`npm test` （Node.js標準テストランナー）。

## 検証状況・制限

- 単体テスト49件成功、JavaScript構文チェック成功、HTTP応答確認
- この実行環境ではChromiumのローカルHTTPアクセスが管理者制限で拒否されたため、**ブラウザ実操作・スマートフォン実機・オフライン復旧は未検証**
- アニメーションは簡易2D図形による独自の小窓演出。完成ドット絵素材ではありません
- 人間化とエンディングは、小規模版として研究条件と選択結果を実装。個体ごとの完全な人間化AI・新たな街での生活・複数階層は含みません
- 仕事・フリマ販売・賃貸は試作ルール。売れ残り・返品・地上全NPCの自律生活は未実装
- 現在の数値は調整仮説です。企画書にある5人試遊、30分安定性、実機負荷、マップ拡張ゲートは未合格です。**一般公開の完成品とは見なさないでください。**
